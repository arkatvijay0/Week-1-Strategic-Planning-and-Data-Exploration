# Raw Data

This folder contains the original datasets obtained for the logistics analysis.

## Files

### DataCoSupplyChainDataset.csv

Main raw supply-chain dataset used as the starting point for the project.

It contains information about:

- Orders
- Customers
- Products
- Shipping
- Delivery
- Sales
- Profit
- Regions
- Markets

### DescriptionDataCoSupplyChain.csv

Contains descriptions and definitions of variables in the main supply-chain dataset.

This file was used to understand the meaning and relevance of dataset columns before analysis.

### tokenized_access_logs.csv

Contains access-log information associated with the dataset.

This file was retained for data-source completeness but was **not used in the logistics analysis**.

---

## Data Status

**Status:** Raw / Unprocessed

No cleaning, transformation, feature engineering, or machine-learning processing was performed on these files.
