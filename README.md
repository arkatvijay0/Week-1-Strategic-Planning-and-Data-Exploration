# DataCo Supply Chain Logistics Analysis

## Week 1 – Strategic Planning and Data Exploration

## 📌 Project Overview

This project focuses on analyzing logistics and supply-chain performance using the DataCo Smart Supply Chain dataset.

The analysis was performed using Python in Jupyter Notebook to identify delivery risks, analyze shipping performance, predict late deliveries, estimate shipping time, segment orders, and support risk-based resource allocation.

## 🎯 Objectives

- Clean and preprocess logistics data
- Perform exploratory data analysis
- Calculate logistics KPIs
- Analyze delivery and shipping patterns
- Engineer logistics features
- Predict late-delivery risk
- Predict shipping time
- Segment orders using K-Means clustering
- Develop a risk-based resource allocation approach
- Generate business insights and recommendations

## 📊 Dataset

The project uses the DataCo Smart Supply Chain dataset.

The cleaned dataset contains:

- 180,519 records
- 52 columns

Major areas include:

- Orders
- Shipping
- Delivery
- Customers
- Products
- Sales
- Profit
- Regions
- Markets
